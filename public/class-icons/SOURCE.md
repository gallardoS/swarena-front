# World of Warcraft class icons

The PNG files in this directory are the 64×64 `Classicon_<class>.png` assets listed by Wowpedia:

https://wowpedia.fandom.com/wiki/Category:WoW_Icons:_ClassIcon

Wowpedia has moved to Warcraft Wiki, so the identical files were retrieved from the corresponding Warcraft Wiki media entries on 2026-09-06:

https://warcraft.wiki.gg/wiki/Category:WoW_Icons:_ClassIcon
